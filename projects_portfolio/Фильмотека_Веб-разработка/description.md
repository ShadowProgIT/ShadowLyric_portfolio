Стек

Backend: Java 21, Spring Boot 4, Maven. База данных не подключена, данные хранятся в памяти процесса.
Frontend: React 19, Vite, axios. Стилизация обычным CSS, без UI-библиотек.

Backend (папка movies)

Разложен по слоям:

model — Movie и Genre. У фильма есть id, название, год, рейтинг, id жанра и статус (WATCH_LATER или WATCHED). Связь жанров и фильмов простая: id жанра лежит полем у фильма.

storage — InMemoryStorage. Два списка в памяти и AtomicLong для генерации id. Метод с аннотацией PostConstruct при старте наполняет хранилище демо-данными: четыре жанра (боевик, комедия, драма, фантастика) и четыре фильма. Наружу возвращаются копии списков, чтобы внутренний массив нельзя было изменить извне.

service — MovieService. Тут бизнес-логика: новому фильму выдаётся статус «К просмотру», при отметке — «Просмотрено». Если фильма нет по указанному id, методы отдают null или false.

controller — MovieController. Эндпоинты на префиксе /api: список фильмов, список жанров, создание фильма, обновление статуса, удаление. На классе висит CrossOrigin с разрешением всех источников, чтобы локальному React-клиенту не требовалась прокси-настройка. Ответ на несуществующий фильм — 404, успешное удаление отдаёт пустой 200.

Frontend (папка movies-frontend)

api.js — единственный слой обращения к серверу: axios-клиент с базовым адресом http://localhost:8080/api и по одной функции на эндпоинт.

components/App.jsx — корневой компонент. При загрузке тянет фильмы и жанры параллельно через Promise.all, хранит всё в своём состоянии и делит список по статусу на две колонки. Обработчики создания, отметки и удаления сначала делают запрос, а потом правят локальный список, поэтому перезагрузка страницы не нужна.

components/MovieForm.jsx — форма добавления фильма с проверкой, что заполнены все поля; жанры подставляются в select тем же списком, что пришёл с сервера.

components/MovieList.jsx — список карточек. Название жанра подставляется по id из общего списка, своего справочника на клиенте нет.

Как запустить

Сервер:

cd movies
./mvnw spring-boot:run

Клиент, в отдельном терминале:

cd movies-frontend
npm install
npm run dev

Дальше интерфейс доступен на http://localhost:5173, API — на http://localhost:8080/api
